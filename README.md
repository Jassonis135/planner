# 个人事务规划

带密码的个人任务管理网站：**https://jassonis135.github.io/planner/**

- 密码解锁（PBKDF2 校验，页面里不存明文）
- 四栏规划：收件箱 / 今天 / 本周 / 以后，可移动、打勾、改优先级、设截止日期
- 规划备忘文本框
- 任务数据用密码派生的 AES-256 密钥加密后存浏览器 localStorage，**不在本仓库里**
- 可选多设备同步：在"设置"里粘贴 fine-grained PAT（只授权私有仓库 `sunggaai-data` 的 Contents 读写），数据以密文形式同步

## 安全说明

本仓库是公开的，但只包含应用代码和密码哈希；任务内容无论在本地还是云端都是 AES-GCM 密文，解密需要密码。
